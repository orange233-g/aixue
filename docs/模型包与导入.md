# 模型包格式与导入

本文说明 ai学 的向量模型包（`.aixue-model`）格式、如何打包、如何发布，以及用户如何导入。

## 1. 设计

- **内置模型**：只保留 `bge-small-zh-v1.5`（约 90 MB），随 APK 分发，开箱即用。
- **可选模型**（如 `Qwen3-Embedding-0.6B`，约 596 MB）：不随 APK 分发，作为独立模型包放在发布页；
  用户下载后在本机导入。模型文件只保存在设备本地（IndexedDB），不上传、不联网。

这样 APK 体积可控（约 110 MB），需要更强召回的用户再单独下载模型包。

## 2. 包格式

`.aixue-model` 就是一个 **zip**（扩展名自定义），要求：

- 所有条目使用 **STORE（不压缩）**：导入时按偏移切片读取，避免整包解压在手机 WebView 里翻倍占用内存；
- 根目录含 `manifest.json`；
- 其余为模型文件，路径与 `manifest.files[].name` 一一对应；
- 单个包 ≤ 2GB（不支持 ZIP64）。

```text
qwen3-embedding-0.6b.aixue-model   (zip)
├── config.json
├── tokenizer.json
├── tokenizer_config.json
├── onnx/model_quantized.onnx
└── manifest.json
```

### manifest.json

```json
{
  "format": "aixue-embed-model",
  "version": 1,
  "model": {
    "id": "qwen3-embedding-0.6b",
    "name": "Qwen3-Embedding-0.6B（进阶）",
    "developer": "阿里巴巴通义千问团队",
    "description": "……",
    "license": "Apache-2.0",
    "dim": 1024,
    "pooling": "last_token",
    "normalize": true,
    "maxTokens": 32768,
    "queryInstruct": "Given a web search query, retrieve relevant passages that answer the query",
    "tokenizer": "bpe",
    "weight": "onnx/model_quantized.onnx",
    "note": "能力强、多语言、32K 上下文；体积大，手机端较慢"
  },
  "files": [
    { "name": "config.json", "size": 1576, "sha256": "……" }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `id` | 唯一 id，小写字母/数字开头，允许 `. _ -`；与已有模型冲突会被拒绝 |
| `dim` / `pooling` / `tokenizer` / `maxTokens` | 推理引擎必需的能力字段（与模型实际结构一致，写错会推理失败） |
| `weight` | 权重文件相对路径，必须出现在 `files` 中 |
| `files[].size` / `sha256` | 导入时逐文件校验，不一致即失败并回滚 |

## 3. 打包

仓库里把「元数据」和「权重」分开放：

```text
model-packages/qwen3-embedding-0.6b/   # 入库：model.json + LICENSE + NOTICE
model-pack/qwen3-embedding-0.6b/       # 不入库：config/tokenizer/onnx 权重
```

元数据目录里的 `model.json` 描述模型与文件清单（不含 sha256），参见
[`model-packages/qwen3-embedding-0.6b/model.json`](../model-packages/qwen3-embedding-0.6b/model.json)：

```bash
npm run pack:model                       # 默认：model-packages/qwen3-embedding-0.6b + model-pack/qwen3-embedding-0.6b
node scripts/pack-embed-model.mjs --meta <元数据目录> --weights <权重目录> --out release
```

输出：

```text
release/qwen3-embedding-0.6b.aixue-model         # zip（约 596 MB）
release/qwen3-embedding-0.6b.aixue-model.sha256  # 整包 SHA256
```

打包脚本会顺带计算每个文件的 size/SHA256 并写入包内 `manifest.json`，把 `LICENSE` / `NOTICE` 一并打进包，
并保持条目 STORE 不压缩。

## 4. 发布

GitHub 对**单个文件有 100MB 硬限制**，所以模型包不能提交进 git 仓库。推荐：

1. 创建 GitHub Release（与代码版本同 tag）；
2. 把 `.aixue-model` 作为 Release 附件上传（单文件上限 2GB）；
3. 仓库里只保留 `model-packages/<id>/`（元数据 + 许可证）与打包脚本；权重目录 `model-pack/` 不入库；
4. 发布说明里贴出下载地址与整包 SHA256，方便用户核对。

`.aixue-model` 与 `release/` 已在 `.gitignore` 中排除，不会误提交。

## 5. 导入

应用内「我的 → 向量模型 → 添加模型」→ 选择下载好的 `.aixue-model` → 导入。

导入流程（`src/ai/embed/importer.ts`）：

1. 读 zip 中央目录（不整包解压）；
2. 解析并校验 `manifest.json`（格式、版本、id、能力字段、文件清单、路径安全）；
3. 逐文件校验大小与 SHA256；
4. 写入本机 IndexedDB（`ai-embed-files`），注册模型并持久化；
5. 任一步失败：删除本次已写入的文件，报错给用户（不留下半套模型）。

导入后即可在「新建知识库 → 检索方式」中选择该模型；模型只能由用户在设置页显式删除。

## 6. 注意

- **内存**：导入 596 MB 的 Qwen3 包时，单文件校验需要一次 `arrayBuffer`（约 596 MB），
  与推理加载权重的峰值相当；建议在电量/存储充足时导入。
- **存储**：模型文件存 IndexedDB，导入后设备占用增加约 596 MB；删除模型或清除应用数据后需重新导入。
- **新增模型**：只要 ONNX 结构与 `embedDirect.ts` 支持的输入（`input_ids`/`attention_mask`/可选
  `token_type_ids`/`position_ids`）和池化方式（`cls`/`last_token`）兼容，即可按同样格式打包导入。
